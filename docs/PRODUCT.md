# 产品设计｜XPIN-Desktop V0.2

**更新：2026-10-16 · 状态：方向确定，用户截图待提供，正式工程未开发**

## 一句话定位

**差点桌面 XPIN-Desktop** 是 Agent 原生的影视化 UI 动效引擎：使用真实系统的视觉识别与交互语义，提供更适合短视频的构图、动画、摄影机、剪辑与可编辑交付。

不是做一个可以日常使用的 macOS / Windows，也不是一套固定播片模板；核心是让 Agent 在不同界面风格间复用**信息表达、操作行为和镜头语言**。

> 让 Agent 像导演一样使用界面，而不是像程序员一样重复造界面。

## 用户与高频场景

- **科技视频剪辑 / Motion Design**：展示照片、文件、网页、参数、文本、下载过程、系统操作，快速形成能剪进 PR / AE 的镜头。
- **产品宣传视频**：将窗口、照片、卡片和数据变成有真实空间与电影化镜头的动态图形。
- **Agent 创作工作流**：用户给照片、文字、视频、图片参考或口播节点，Agent 组织操作、镜头、动画和交付。
- **团队协作**：所有人使用统一外观 Skin 和高质量行为库；人工直接在 HTML 中修改素材和参数。

## 四个不可丢的目标

1. **可信**：系统辨识度清楚、窗口与控件行为正确；不追求毫无必要的逐像素复制。
2. **影视化**：界面本身是摄影的对象；支持全景、中景、特写、局部放大、切镜、景深和转场。
3. **可编排**：一套高层语义动作能在 macOS / Windows / 移动端 / Node Canvas 等不同皮肤中映射到各自交互。
4. **可修改**：素材、布局、动作、镜头、时间点分离；单处修改尽量不破坏整段视频；HTML 可视化调整与 Agent 调整并行。

## 默认设计模式

- **Native**：贴近真实系统，适合教程和真实操作展示。
- **Cinematic（默认）**：保留真实系统特征，优化窗口比例、字体、间距、阴影、光影、镜头与节奏。
- **Creative**：可超越系统逻辑的独立 UI Motion，支持节点卡片、HUD 等，但仍复用同一底层。

这三种是外观与表演强度，不是三套分叉工程。

## 三种空间形态

- **Desktop Space**：桌面、壁纸、文件图标、Dock / Taskbar、窗口完整存在；建立场景与可信操作。
- **Floating Stage**：弱化或隐藏桌面，让窗口成为空间中的产品主体，允许深度、轻微视角与柔和投影。
- **Graphic Canvas**：照片、文字、参数卡、图标和连线可脱离系统边框进行 Motion Design 编排。

目标支持形态连续转换，例如：桌面 → Preview → 图片卡片 → 节点关系图。

## 多界面家族：扩展方向，不代表现已完成

| 家族 | 代表内容 | 优先度 |
| --- | --- | --- |
| macOS | Finder、Preview、Safari、Dock、通知 | **首期唯一视觉基准；优先 Finder / Preview** |
| Windows | Explorer、Photos、Taskbar、Settings | macOS 验收后，以可替换 Skin 扩展 |
| Node Canvas | 图文节点、端口、连线、分组与卡片 | 第二阶段 |
| iOS | Home、Photos、Settings、Notification / Control Center | 后续 |
| Android | 主屏幕、相册、文件管理、通知面板及品牌变体 | 后续 |
| Custom UI | 网页、终端、表格、FUI、概念科技面板 | 按场景扩展 |

**系统 Skin、UI 组件和导演表现解耦**。不要为每个系统复制一套动作引擎。

## 首期视觉来源（2026-10-16 已定）

用户将提供**现有 macOS 风格视觉模板的截图**，只以截图作为视觉参考，由 Codex 用代码重新搭建可编辑 UI 组件；**不以 AE 工程或 AE 数据迁移作为输入/依赖**。截图尚未提供，视觉 Token 与关键帧对照需等待实际素材。详见 [macOS 视觉基准](MACOS-VISUAL-REFERENCE.md)。

**开发顺序**：先 macOS 截图风格卡 → 关键帧对照 → 动态 Previs → 组件与语义动作 → 可编辑 HTML + MP4；后续系统再使用同一场景数据与行为引擎切换 Skin / 操作适配器。

## 典型用法

**镜头 A｜放大产品照片**：双击桌面图标 → Preview 打开 → 镜头推进 → 滚轮缩放到芯片 → 标注显现。

**镜头 B｜三图对比**：Finder 选择三个文件 → 窗口分列 → 自动构图 → 三个参数顺序强调 → 合成比较卡片。

**镜头 C｜跨媒介切换**：浏览器打开官网 → 页面产品图转成独立 2.5D 卡片 → 转场至三维产品镜头（外部 Blender / AE）。

**镜头 D｜节点概念图**：用户提供多条信息 → Agent 建立节点关系与图文卡片 → 连接线与镜头按口播节奏依次展开。

## 使用体验

**Agent 快速镜头模式**：一句话 + 素材 → 自动分镜与时间线 → 动态预演 → 生成可编辑 HTML / 按需视频。

**导演场景模式**：分段口播 + 镜头要求 → 一组 UI 场景与镜头组接 → 支持锁定画面和时点，再局部调整。

**人工编辑模式**：中央预览、左侧组件/素材、右侧参数、底部时间线。可直接替换图片、编辑文字、移动窗口和修改动画。

## 非目标与边界

- 不实现真正的文件系统、网络浏览器、跨设备远程控制或可用的 OS。
- 不保证 100% 原生系统布局/动画复刻；系统和品牌资产需考虑授权。
- 不在 V0.1 追求海量系统 App、复杂 3D 物理效果或原生 AE / PR 插件。
- 不因为“一个 HTML 能跑”就宣布完成：还必须验证时间码确定性、素材修改、可复现渲染与 Agent 编排。

## 产品成功标准

用户能快速把真实素材变成**可信、清晰、审美在线、镜头节奏可控的影视 UI 片段**，并能用一句修改指令或编辑器局部调整，而非从零重做。
